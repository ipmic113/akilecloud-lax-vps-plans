## 五组线路的区别，以及 LAXPro 贵在哪

LAXLite 和 LAXHyper 是普通国际线路堆带宽。5Gbps 端口、TB 级流量、十几块到几十块一个月，拿来跑中转、下载站、海外静态资源很划算。官方明确不保证中国大陆直连，晚高峰回国延迟会上去，别把它当稳定回国线路用。

LAX4837 的核心是三网回程 CUVIP(4837) 加原生 IP、双 ISP 家宽属性，宿主机是 AMD EPYC 配 NVMe SSD。它适合需要美国原生 IP 信誉的业务，比如注册、电商、流媒体中转。全系只有原生 IPv4，没有 IPv6，需要 IPv6 的别选。ISP 版从 ¥54.99/月起，非 ISP 版从 ¥24.99/月起，差价买的是双 ISP 原生 IP 属性，不是配置。

LAXPro 是洛杉矶唯一明确针对大陆访问做三网优化的系列之一，电信 CN2 GIA、联通 9929、移动 CMIN2，原生 IP，官方标注 DNS 流媒体解锁和单 IP 20Gbps DDoS 防护。它的带宽只有 500Mbps，入门档流量 300GB。拿 ¥43.74 的 LAXPro-Light 和 ¥34.99 的 LAXLite-Starter 比，后者给 5TB 流量和 5Gbps 端口，流量差 16 倍。LAXPro 贵在线路，不在配置。

LAX Premium 也是三网双向优化，联通 9929、移动 CMIN2、电信 CN2 GIA，原生 IP，第三方资料提到带单 IP 20Gbps DDoS 防护。它的入门价 ¥79.99/月、带宽 200Mbps，比 LAXPro 更贵也更窄。官方资料没有把 Premium 和 LAXPro 的线路差异写清楚，买之前看下单页的线路说明。

## FAQ

**美国节点能解锁 Netflix 吗？**
官方对 LAXPro 标注了原生 IP 和 DNS 流媒体解锁，但没有列具体平台清单。香港 HKLite 和日本系列在官方说明里写了解锁当地流媒体。美国节点具体能看哪些平台，开通后自己测最准，别按“一定能看美区 Netflix”下单。

**LAXPro 和 LAXLite 差在哪？**
LAXPro 贵在三网优化线路，带宽 500Mbps、流量 300GB 起；LAXLite 是普通国际线路，5Gbps、1TB 起。只看带宽和流量，LAXLite 划算得多；要大陆访问稳，才考虑 LAXPro 的溢价。

**优惠码怎么用？**
在结算页或产品详情页右上角的兑换码框填入，确认后自动折扣。部分码领取后 30 分钟内有效，过期要重新领。

**能退款吗？**
3 天内退 80%，3 到 7 天退 50%，7 到 10 天退 20%，超过 10 天不退；退到账户余额，不原路退回；特价机不退款。以官网服务条款为准。

**洛杉矶哪个套餐最适合建站？**
看访客在哪。海外访客为主，LAXLite-Mini ¥15.99/月，1核 2GB、10GB 硬盘、2TB 流量够用；国内访客为主，LAXPro-Light ¥43.74/月起，但要先算 300GB 流量够不够。不管哪档，硬盘选 20GB 以上更稳。
